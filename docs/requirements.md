| Требование | Выполнение и доказательство |
|---|---|

| Оценка 20 эпизодов | Отдельные seed=2000..2019, каждый эпизод в `eval_*.json` |
| Видео пяти эпизодов | PPO, seed=3000..3004, 2500 кадров; ссылка в README; `results/video_ppo.json` |
| Видео на YouTube/Диске, не в Git | Google Диск; резервная MP4 в Release; `.gitignore` исключает видео |
| Гиперпараметры в YAML | `configs/*.yaml`, использованный снимок в `results/*/train.json` |
| Объяснить изменения гиперпараметров | Сети и параметры оптимизации сохранены из шаблона; бюджет 100000 ->100352 для одинакового фактического числа шагов |
| MDP | `docs/mdp.md`: состояние, действия, награда, переходы, горизонт |
| TensorBoard и веса | `runs/`, `models/` в архиве Release; в Git исходные CSV/JSON |
| Отчёт 5–7 страниц, все разделы | `docs/report.pdf`, 6 страниц; текст `docs/report.md` |
| Коммиты step-1, step-2 и далее | Реальные этапы в истории Git |
| Тег v1.0 и Release | Публикация `releases/tag/v1.0` |
| CI и тесты | `.github/workflows/ci.yml`, линтер, тесты, независимый пересчёт метрик |
