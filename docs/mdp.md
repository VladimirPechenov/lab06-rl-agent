# MDP: CartPole-v1

Задача: удерживать вертикальный шест, управляя горизонтальной силой тележки.

- **Состояние S:** вектор float32 `[x, x_dot, theta, theta_dot]`: координата (м), скорость
  (м/с), угол (рад), угловая скорость (рад/с). Наблюдение содержит все четыре компонента.
- **Действия A:** `Discrete(2)`: 0 = сила -10 Н, 1 = +10 Н. Одно действие на шаг 0,02 с.
- **Награда R:** +1 за каждый шаг, включая шаг завершения; цель - максимизировать сумму.
- **Переходы:** детерминированная физика среды после случайного начального состояния;
  при reset четыре компонента выбираются независимо из U(-0,05; 0,05).
- **Завершение:** `terminated` при |x| > 2,4 м или |theta| > 12 градусов (около 0,20944 рад).
  `truncated` при достижении лимита 500 шагов. Оба флага завершают цикл оценки и записи.
- **Дисконт:** gamma = 0,99; максимальная недисконтированная награда эпизода 500.
- **Порог задания:** средняя награда >= 450 на 20 эпизодах. Это порог лабораторной;
  в спецификации Gymnasium порог среды равен 475.

Начальные состояния обучения seed=42; валидации seed=1000..1009; итоговой оценки
seed=2000..2019; записи seed=3000..3004. Итоговая оценка не используется для выбора
контрольной точки: оценивается финальная модель после всего бюджета обучения.

PPO: on-policy actor-critic с ограничением изменения политики; DQN: off-policy
Q-функция, replay buffer и отдельная target network. Все изменяемые параметры
эксперимента - в `configs/ppo.yaml` и `configs/dqn.yaml`.

Источник: https://gymnasium.farama.org/environments/classic_control/cart_pole/
